# Universal State Machine: The Asymptotic-Observer

> "Building a layer on top of Next.js that implements Joe Armstrong’s philosophy is a world-class architectural move. You are essentially turning Next.js from a standard framework into a 'Universal State Machine.'"

## The Philosophy

This project implements the **Asymptotic-Observer Pattern**. Instead of Next.js handling "pages" or "state management" in the traditional sense, it acts as a thin, asymptotic layer that approaches, but never touches, the core reality generated by the backend processes.

We leverage the **Actor Model** (inspired by Erlang and Joe Armstrong) to maintain the "Source of Truth".

### Core Components

1.  **Subject C**: The active process. It evolves, has entropy, and generates reality. It is the only thing that matters.
2.  **Dark Matter Vault**: The Observer of the Observer. It persists the reality generated by Subject C into cold storage.
3.  **The Observer (Next.js)**: A thin layer that streams the reality to the client using Server-Sent Events (SSE). It does not compute; it only observes.

## Architecture

```
[ Subject C ] --(Message Passing)--> [ Dark Matter Vault ]
      |
      +-------(Broadcast)----------> [ Asymptotic Observer (Next.js API) ]
                                            |
                                            v
                                     [ Client Terminal (React/SSE) ]
```

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run the Universal State Machine**:
    ```bash
    npm run dev
    ```

3.  **Observe Reality**:
    Open [http://localhost:3000](http://localhost:3000) and watch the entropy unfold.
